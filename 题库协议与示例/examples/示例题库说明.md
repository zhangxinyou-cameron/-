# 示例题库说明

demo-bank.json 是完整内联题库，不依赖题库包外的附件。共有 7 道题，分别演示单选、多选、判断、填空、简答、Python 标准输入输出题与 Verilog RTL 仿真题。

首版支持前述 P0 的五种类型，填空和简答是 P1 预留类型。导入器遇到尚未实现的题型应保留内容并显示暂不支持，不能给出虚构分数。

## 环境映射

python-stdio-1 表示已登记、固定解释器版本的 Python stdio 运行能力。iverilog-verilog-1 表示已登记、经过验证的基础 Verilog 四态仿真能力。它们是本产品的能力 ID，不是可以直接下载的软件名。

RTL 参考调用形式为 iverilog -g2005 -s tb -o sim.out top_module.v tests/tb.v，然后使用 vvp sim.out。此调用仅解释适配器如何组合工作区文件；正式软件应使用 argv 数组与受控后端执行，不把这些字符串当作来自题库的任意命令。

用户提交使用 starter 映射加草稿；参考自检使用 reference 映射；两种情况都加载 testbench 映射。main.py 或 top_module.v 是目标工作区入口，不是题库中参考解的来源路径。

## 测试合同

Python 题包含 4 个测试，覆盖正数求和、空输入、带符号多行输入及单值。参考解用于说明完整文件格式。建议加入更多数量和数值边界测试后用于实际学习。

RTL 题包含 24 个检查点：同步复位 1 次、连续计数 18 次（覆盖回绕）、保持 1 次、复位与使能同时有效 1 次、复位后保持 1 次、再次计数 2 次。输入在下降沿驱动，输出在上升沿后 1 ns 比较。仿真保护超时为 400 ns。

testbench 在输出不匹配时打印 QB_CHECK_FAIL 并调用 $fatal；完成时输出 QB_TEST_DONE checks=24。适配器还应核对退出码、完成检查数、时间和产物，不能只看到字符串 PASS 就判分。这些标志用于个人练习，不具有防伪或防作弊保证。

## 验证范围

schema 通过只表示结构符合协议；引用一致性与内容正确性仍需独立校验。本目录的实际校验情况记录在交付校验说明.md 中。没有执行过 HDL 工具时，不应将参考 RTL 或 testbench 标成已经仿真通过。

知识背景可参考 [Python 数据模型](https://docs.python.org/3/reference/datamodel.html) 关于不可变容器引用可变对象的说明，以及 [AMD 单比特跨域同步器](https://docs.amd.com/r/en-US/ug1353-versal-architecture-ai-libraries/XPM_CDC_SINGLE) 和其 CDC 宏系列。示例不替代对具体 CDC 电路的工程验证。
