# 可复用提示词

下面的模板用于用户要复制给其他 AI 的场景。使用时按已知需求填实，附上 qbank.schema.json，并按需附 assets/example-bank.json。保持用户要求的题量与范围；不要让模板中的示例约束替代实际需求。

## 新建题库

```text
请为知习个人技术刷题软件生成 QBank 1.0 题库。
学习目标：填写具体知识或能力。
学习者基础：填写当前基础。
知识范围与不包含内容：填写范围。
题型、题量与难度：填写用户要求或明确的默认安排。
目标软件：知习 0.1.0。
可用环境：填写已确认的环境；未知时列出需要的环境，不声称已安装。
题库 ID 与发布版本：填写稳定 bank_id 与 x.y.z 版本。
提供资料：填写用户资料与可引用出处，没有则说明原创整理。

严格遵循附带 JSON Schema。交付一个完整 UTF-8 JSON 对象，不使用注释、尾逗号、重复键、代码围栏或省略号。
外层必需包含元数据、knowledge_points、questions、files，无附件时 files 为 {}。只有 extensions 可自由扩展，不自报 verified 等未定义字段。
题目知识点与主知识点引用必须存在；ID 稳定且唯一；单选答案指向已有选项，多选为无重复选项集合，判断使用布尔值。
题干明确前提、边界和适用版本。题型和知识点合理覆盖，避免重复换词题；解析说明正确理由与错误选项。提示逐步引导，不直接复制完整答案。
来源、网址、页码与授权只记录真实信息，不知道就说明原创或未核实。

初版自动判分题型为 single_choice、multiple_choice、true_false、code、rtl。填空和简答仅在我明确要求时生成，并说明暂不自动判分。
code 使用完整程序的 stdio 协议，环境仅 python-stdio-1、c11-stdio-1、cpp17-stdio-1。明确数据范围、输入输出和空输入行为；至少一个样例与一个正式用例，覆盖关键边界。
starter、reference 源码放在 files 内联；两组分别通过 source_path/target_path 映射到工作区入口。输出不含交互提示；trim_end 仅忽略整体末尾空白，不提供数值容差。
rtl 使用 iverilog-verilog-1 与基础 Verilog-2005。明确端口、时钟复位、优先级、位宽、延迟、参数和时序单位，提供独立自检查 testbench。
testbench 避免驱动/采样竞态；检查数与 check_count 一致；失败输出 QB_CHECK_FAIL 并非零退出；正常单独输出 QB_TEST_DONE checks=N。在 testbench 内实现仿真超时，波形文件固定 wave.vcd。
编程与 RTL 题的 limits 必须包含 schema 所需全部字段，源码和附件路径不能越出题库或任务目录。
不要编造不支持的环境已经可运行，也不要把宿主机安装命令放进题库。

输出前核对格式、引用、答案、文件映射、测试数和内容正确性。只有实际运行过的参考解或仿真才声称已经通过；结构校验与知识核验分开说明。若只允许返回 JSON，检查情况不添加到 schema 未定义位置。
```

## 修复或更新

```text
请修复附带的 QBank 1.0 JSON，并依据提供的已发布版本保持可导入性。
输入包括：原始题库、JSON Schema、错误报告，以及存在时的已发布基线。
只修复报错和必要关联项，保留其他题目、稳定 ID、题意与有用测试。
已发布题目的任何业务字段或引用文件改变，都递增 revision；发布内容改变时递增 bank_version。尚未发布的草稿格式修复可以保持初始版本。
相同 bank_id、question.id、revision 下不交付不同内容。不要用删测试、删题、改变预期输出迎合错误参考解或放宽判分来掩盖问题。
知识性争议需根据题意与来源核实，不能伪造引用。保持修改后答案、解析与测试彼此一致。
交付完整可解析 JSON；如果我明确要求增量，只交付变化题并说明其为增量。不得遗漏应保留内容或输出半个文件。
```

## 环境需求

```text
请为以下题库整理运行环境需求与健康检查方案。
目标系统与架构：填写。
已有工具和执行后端：填写探测结果或说明未知。
语言、版本、第三方库、仿真语义：填写。
软件当前支持：Python stdio、C11 stdio、C++17 stdio、基础 Verilog-2005/Icarus。

优先复用已安装工具、应用私有环境和软件预设。列明所需能力、版本、来源、许可、磁盘需求、检查方法及可能的系统权限或重启。
不要编造下载地址或 SHA-256；未核实内容明确标注。知习 0.1.0 尚未实现任意 AI 安装脚本接口，不提供可以直接导入执行的虚构 envpack。
本次只生成环境方案，不执行安装或修改系统 PATH。若我另行明确要求配置，再按照实际接口处理。
```
