# 知习 v0.2.0：启动器与启动过场

日期：2026-10-27；Windows x64；Electron 45.0.0。

## 交付

- 工作区根目录和便携版内的 `知习.exe`：Windows GUI 启动器，使用本机 .NET Framework 编译并嵌入知习图标。按所在位置寻找主程序，使用进程 API 传递参数，不经过命令行 shell。
- 芯片、电路和轨道动画，真实初始化步骤进度，完成淡出后显示主工作台。
- 24 条中文学习寄语，本地持久化随机轮换；一轮内不重复，跨轮避免相邻重复；不联网获取。
- 启动失败显示错误和重试/退出；45 秒无正常完成信号时显示超时错误，不伪造完成。
- 多次启动沿用现有单实例机制，恢复并聚焦现有窗口，不重复开启学习工作区。

## 行为边界

百分比表示已完成初始化阶段的权重，不是剩余时间预测。达到 100% 后保留极短的展示与淡出时间；无定时器递增假进度。系统减少动态效果偏好会关闭非必要动画。

本次没有安装系统服务、设置开机自启或修改系统 PATH。启动器是入口，仍需保留配套软件文件夹。
