## 复现命令

```powershell
npm test
npm run test:ui
```

验证便携版时，在 PowerShell 中设置 TECH_PACKAGED_EXE 为实际 TechPractice.exe 的绝对路径，再执行 npm run test:ui。自动化会使用新的隔离数据库并在结束时关闭测试窗口。
