# 知习 0.3.0 插件与学习中心测试报告

测试日期：2026-11-09。环境：Windows x64，Node.js，Electron 桌面程序。所有自动化测试使用独立数据库与 Chromium profile，未改动个人学习数据。

## 第一轮：后端与数据

`npm test`：23 项通过，包含 15 项原核心测试、8 项插件与学习专项测试。

专项覆盖：插件生命周期与开关持久化、禁用后的接口拦截、启动失败隔离、磁盘写入失败时开关回滚；非法课程、缺失引用、同版本冲突、旧版拒绝；内嵌 QBank 与课程原子导入；已读和独立 AC 的双重完成条件、辅助通过不计入、正文修改重置已读；升级和备份恢复保留笔记；修改正文的导出版本单调递增；空白正文拒绝保存且不部分写入笔记。

## 第二轮：真实学习界面

先运行源码版界面流程，修复阅读勾选的异步受控状态后重新验证。随后在打包程序运行 `npm run test:learning`，9 项流程通过，渲染错误为 0；后端持久化修复后再次运行打包回归通过。

1. 无效课程拒绝导入且数据不变。
2. 粘贴 AI JSON 导入课程和题库，打开章节阅读器。
3. 编辑正文、保存笔记及 Markdown 脚本清洗。
4. 实际选中文字摘录到笔记并保存。
5. 取消离开提示后保留未保存编辑。
6. 已读 → 实际章节答题 → 独立通过 → 闭环完成。
7. 导出包含修改正文、递增版本且不包含私人笔记。
8. 关闭插件移除导航并拦截后端访问。
9. 重启、重新开启插件后保留正文、笔记、阅读和答题进度。

另以全新隔离数据启动便携程序，点击“导入入门课程”，验证内置示例导入及章节笔记保存，并目视检查实际三栏阅读界面。预览见仓库 docs/学习中心预览.png。

## 第三轮：核心与启动回归

打包程序 `npm run test:ui`：8 项通过，无渲染错误。覆盖原页面、判断题、收藏与笔记、真实 Python 样例和正式评测、题库导入、统计追溯及备份导出。

打包程序 `npm run test:startup`：4 项通过，无渲染错误。覆盖真实启动阶段、语录轮换、原生 EXE 唤醒已有实例、损坏数据库的错误与重试。

`npm run build` 完成 TypeScript 检查、Vite 前端构建、后端与 Windows 启动器构建。插件开发 Skill 通过 quick_validate.py 校验。

## 范围

插件为随版本构建注册的可信模块，当前未提供动态下载第三方插件或插件沙箱。文档阅读与编写支持 Markdown；未实现 Word/PDF 编辑、联网 AI 对话和跨设备同步。本轮没有新增运行器或重做全部 Verilog 题库仿真，原有语言评测接口继续复用。未执行万题量级性能验收。

测试脚本位于 tests/plugins.test.mjs、tests/learning-ui.mjs 及已有核心测试；JSON 结果保存在本地 test-results/，不提交测试数据库或缓存。
