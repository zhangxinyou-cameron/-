# 知习 技术练习室

面向个人数字 IC、C/C++ 和 Python 学习的 Windows 桌面软件，版本 0.4.1。

## 直接使用

双击工作区的 `知习.exe`，或 release/TechPractice-win32-x64/知习.exe。完整保留它所在文件夹；不需要安装 Node.js 或 npm。首次启动会导入 3 套原创示例题库，共 16 题。示例仅用于入门和演示，可在题库编辑器中修改。

程序使用本地 SQLite 数据库；默认数据目录为 %APPDATA%/TechPractice。软件启动目录与个人学习数据分离，更新程序文件不会覆盖学习记录。可以在“偏好与数据”中打开实际数据目录、导出备份和恢复。

## 启动过场与语录

启动时显示芯片与电路动效、百分比及当前准备步骤。进度依次对应读取学习记录、整理题库、恢复练习、检查备份、载入工作台；只有实际界面数据准备好后才达到 100%，随后自动进入主界面。加载完成后有很短的展示与淡出时间，便于看清寄语；不以定时器伪造百分比。

内置 24 条学习寄语，自动打乱轮换，一轮内不重复，跨轮也避免紧邻重复。轮换历史保存在数据目录的 `startup-quotes.json`，不需要联网。系统开启减少动态效果时，启动过场会减少动画。

已有实例时，双击启动器会唤醒当前窗口。启动异常会保留实际进度、显示错误并提供重新启动/退出。第一次体验新版时，请先正常退出原有窗口再打开 `知习.exe`，以加载新启动流程。

## 学习中心与插件

在“插件管理”中开启或关闭学习中心。开关跨重启保存，关闭保留课程、正文修改、笔记与进度。当前采用随应用构建注册的可信插件；插件开发契约见同目录《插件开发协议.md》，AI 开发 Skill 位于源码仓库 skills/wisdom-plugin-developer/。

在“学习中心”点击“导入入门课程”即可体验两章 Verilog 学习资料，也可导入 learnpack-demo.json、其他 LearnPack 文件，或粘贴 AI 按《学习资料协议.md》生成的 JSON。课程可以内嵌 QBank，课程与题库一并校验、原子导入。

每章包含知识点、Markdown 正文和对应测试。可以阅读、编辑正文、选中文字摘录、编写并预览章节笔记；修改后请点击保存，切换页面和关闭窗口时会提醒未保存内容。当前提供 Markdown 文档能力，不直接导入 Word/PDF。

阅读后开始章节测试即可自动确认本章已读，也可手动勾选“我已完成本章阅读”。练习页面实时显示本章进度，可直接返回本章或进入下一章；最后一章可返回课程列表查看总进度。重启后从“继续上次”进入章节测试仍保留课程来源。已读且每道课后题正式作答过即算本章学完，无论对错，辅助作答也计入；样例运行、环境异常和取消运行不计入。下一章入口只在最后一道题出现，全部题目作答后启用。独立通过率仍单独用于掌握和复习统计。正文修改和课程升级会要求重新确认阅读；学习进度和笔记沿用 SQLite 备份恢复。

导出课程会包含保存后的正文修改和对应题库，不包含个人笔记与作答记录。修改后的导出课程自动递增补丁版本，避免同版本内容冲突。

## 开始练习

1. 在“今日学习”开始一轮练习，或到“我的题库”筛选题目。
2. 单选、多选、判断题提交后立即反馈。未作答不能提交；判断题的“错误”是合法答案。
3. 在编程题编辑器中写代码。“运行样例”只调试，“正式提交”执行全部测试并保存记录。
4. 错误题自动进入错题本；收藏与 Markdown 笔记独立保存。
5. 首次独立通过后安排次日复习；后续按到期复习表现逐步增加间隔。提示或答案会标记辅助练习。

## Python 与编译工具

便携版随带官方 Python 3.12.10 embeddable 解释器，基础标准库题不需要单独安装 Python。默认执行后端为容器；要直接使用内置 Python，在“运行环境”选择“本机环境”，对需要练习的题库确认信任当前内容。

本机模式以当前账户权限运行代码，只控制超时和输出，不能严格隔离内存、进程、文件或网络。外来或不确定来源的代码建议在容器中运行。

C11、C++17 和基础 Verilog 评测适配器已实现。使用本机后端时，需要检测到 GCC/Clang、Icarus Verilog 与 vvp；可在环境中心选择相应可执行文件，不会修改系统 PATH。

容器后端需要用户已安装并启动 Docker。环境中心可展示并执行应用内置的镜像准备计划，独立检测通过后才登记可用。实际运行禁用容器网络，限制 CPU、内存和进程数，使用只读根文件系统以及独立工作目录。WSL2 和 Docker 的安装、系统权限与重启由用户按官方说明完成。

初版支持 Icarus 的基础 Verilog-2005 路径和 VCD 波形导出，不承诺完整 SystemVerilog/UVM、综合、STA 或 CDC 自动验证。

## 用 AI 生成题库

在“导入题库 → 让 AI 帮你出题”中导出工具包，内含 QBank 1.0 Schema、提示词和完整示例。将它们给你选择的外部 AI，填写学习目标、数量和运行环境。得到 JSON 后粘贴校验，或导入 .json / .qbank.zip。

导入先检查 JSON 重复字段、Schema、ID、选项答案、知识点、文件映射、附件摘要和安全路径，再展示新增、更新、未变、旧版及冲突。相同 ID 与 revision 的内容改变会阻止覆盖，需递增 revision；旧作答快照仍可查看。

题库包根目录包含 bank.json。文本可内联；二进制附件按协议放入包中。初版仅显示包内 PNG/JPEG，忽略远程图片和可执行 HTML。AI 内容通过结构校验不代表知识已经正确。

## 后续范围

填空与简答题目前支持阅读、解析和笔记，暂不自动判分。软件内 AI 对话、任意 AI 安装脚本接口、完整长期学习计划、模拟考试、内嵌波形查看、断点调试和跨设备同步留待后续版本。

本机后端尚未实现 Windows Job Object 强制内存/进程配额；严格限制需要容器。安装时可以固定镜像标签，正式运行记录具体镜像 ID；重新下载镜像不等于重现历史环境。依赖与工具链更新后应重新回归。

初版以核心流程可用为目标，尚未执行设计文档中 1 万题 / 10 万作答记录的性能验收。原核心范围见 TEST_REPORT.md；0.3.0 插件与学习功能的多轮验证见 LEARNING_TEST_REPORT.md。

## 开发与构建

需要 Node.js 24 和 npm。源代码位于 src/ 和 desktop/。前端使用 React、TypeScript 与 Monaco，后端使用 Electron 和 sql.js，学习数据库为实际 SQLite 文件。

```powershell
npm ci
node scripts/prepare-assets.mjs
npm test
npm run build
npm start
npm run package
```

prepare-assets.mjs 优先从上级设计文档目录复制协议和示例；没有上级文档时，使用源码包中已经附带的 assets 资源，再生成入门题库。便携 Python 位于 assets/python，来自 Python 官方 Windows embeddable 包，需与其许可证一起保留。打包脚本复用安装好的 Electron 运行时，将本地前端、后台和资源复制到 release/TechPractice-win32-x64。

若 npm 阻止 Electron 的安装脚本，可按 npm 的脚本批准机制确认该已安装依赖的脚本，或在审查后执行 node node_modules/electron/install.js 下载运行时。不要将软件的环境安装权限与开发工具安装权限混为一谈。

# 本机 Verilog 环境补充（2026-10-27）

本工作区已配置 MSYS2 的 Icarus Verilog 13.0 与 GTKWave 3.3.127，位于上级目录 `tools/verilog-msys2/ucrt64/bin`。本机后端会自动发现源码版/便携版共同工作区中的这个目录；无需修改系统 PATH。已有窗口需重启一次以加载环境修复。

修复 Windows 传递重复 `PATH`/`Path` 时丢失工具目录的问题。20 道 RTL 参考解在真实运行器通过 2232 检查点，20 个错误实现全部返回 WA；13 项核心回归通过。完整说明见工作区的 `Verilog环境配置说明.md`。工具链为单独安装，不包含在原应用压缩包内。


## 从仓库更新

左下角自动检查仓库提交，发现新版本后点击“可更新”即可同步源码并构建；就绪后点击“重启完成更新”。需要本地源码仓库、Git、Node.js 24+ 与 npm。未提交修改、分支冲突、未保存章节编辑或正在运行代码会阻止更新。更新会备份学习数据并保留原程序目录。详情见仓库 docs/软件更新.md。

学习中心的课程卡片显示已读章节、已作答题数、已学完章节与百分比。阅读器自动保存最近章节和滚动位置，退出课程或重启后点“继续学习”恢复，不再默认从第一章开始。
