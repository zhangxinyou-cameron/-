# 知习 v0.2.0 启动说明

双击本文件夹中的 **知习.exe** 即可开启软件。原有「启动知习.cmd」也已改为调用这个入口。

首次体验本次更新，请先正常退出已经打开的知习窗口，再双击知习.exe。日常重复打开时会唤醒现有窗口。

启动过场包含芯片与电路动画、实际初始化进度、当前准备步骤，以及 24 条按轮次打乱、循环不重复的学习寄语。准备完成后自动进入练习室。启动失败会显示错误及重新启动/退出按钮。

请保留以下目录关系：

```text
刷题/
├── 知习.exe
├── tech-practice/
│   └── release/TechPractice-win32-x64/TechPractice.exe
└── tools/    （已配置的本机 Verilog 工具）
```

如果使用单独下载的便携软件包，则直接双击其文件夹内的知习.exe，保留整个文件夹。启动器为 22KB 左右的 Windows GUI 程序，启动时没有命令行黑框；主程序依赖仍位于软件文件夹中，不能仅复制这一个 exe 作为完整软件。

学习数据库沿用 `%APPDATA%\TechPractice`。语录轮换记录单独保存在该目录的 startup-quotes.json，不改动题库与作答。既有的 Verilog 工具配置继续生效。
