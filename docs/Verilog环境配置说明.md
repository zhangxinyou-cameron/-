**关闭并重新打开当前知习窗口一次**，在「运行环境」选择本机环境，Verilog 会自动显示可用。当前学习设置已经是本机模式，无需修改系统 PATH 或手动选择文件。

自动识别会从源码版和便携版所在目录向上查找 `tools/verilog-msys2/ucrt64/bin`。请保留当前目录关系；若将软件与工具分开放置，可在「运行环境」手动选择实际的 `iverilog.exe` 和 `vvp.exe`。
